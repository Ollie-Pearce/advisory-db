# Memory corruption bug on `Window` type

The `Window` type contains a raw pointer which can be duplicated via a derived `Clone` implementation without incrementing a reference counter. 

If an instance of `Window` is duplicated through `Clone` and both instances are dropped memory corruption can occur.
